คู่มือ Sweetprops

1 · เชื่อมกับ Roblox Studio

  1. เปิด Roblox Studio แล้วเปิด place ที่จะใช้
  2. เปิดแผง Assistant → เมนู ⋯ → Manage MCP Servers → เปิด Enable Studio as MCP server
  3. กลับมาที่ Sweetprops มุมซ้ายบนจะขึ้น เชื่อมแล้ว ถ้ายังไม่ขึ้น กดที่สถานะเพื่อลองเชื่อมใหม่

2 · สร้างโมเดล

  • AI เมช — เมชเนียนมีลาย สวยที่สุด เหมาะกับของตกแต่ง ตัวละคร และอาหาร (AI วาดจากคำอธิบาย ไม่ได้ดูรูป)
  • ประกอบชิ้นส่วน — สร้างจาก Part ธรรมดา แก้สีหรือขยับทีละชิ้นได้ และมี Attributes ให้ปรับค่าต่อได้
  • จากรูปต้นแบบ → การ์ด 2.5D — เหมือนภาพ 100% ลบพื้นหลังให้อัตโนมัติ ผ่าซ้าย-ขวาพับเป็นตัว V แล้วอัปโหลดเข้าบัญชี Roblox ของคุณ เหมาะกับปีก ป้าย ของแบน และของแฟชั่น
  • จากรูปต้นแบบ → AI 3D ตามรูป — เป็น 3D จริงมองได้รอบตัว แต่ไม่เหมือนเป๊ะ ติ๊ก “ทำคู่” เพื่อให้ได้แบบ AI เมชมาเทียบด้วย
  • มี แผ่นแปลน หลายมุม? กด ✂ ครอปเฉพาะส่วน แล้วเลือกแค่ FRONT VIEW ก่อนสร้าง

โหมดมือโปร (ให้สวยและใกล้รูปขึ้น)

  • สร้างพร้อมกัน 2–4 แบบ — AI สุ่มผลทุกครั้ง สร้างหลายแบบแล้วเลือกตัวที่สวยสุด ลบตัวที่เหลือในหน้าปรับแต่ง
  • ย้อมสีลาย — เปลี่ยนสีลายที่ AI วาด (เช่น ขาวอมฟ้า → ชมพูพาสเทล) โดยยังเก็บรายละเอียดขนนกไว้
  • วัสดุมือโปร — ชิ้นที่เป็นทอง/โซ่/กรอบ เปลี่ยนเป็นโลหะทองเงา ชิ้นที่เป็นอัญมณี เปลี่ยนเป็นแก้วใสเรืองแสง
  • แขวนจี้คริสตัล และ โปรยดอกซากุระ/หัวใจ/ไข่มุก บนผิวโมเดล
  • ชุดสำเร็จรูป — กดปีกแฟนซี มงกุฎ ดาบ ฯลฯ เพื่อตั้งค่าทุกอย่างให้ในคลิกเดียว

ใส่ตัวละคร (Accessory)

หน้าปรับแต่ง → 🧍 ใส่ตัวละคร เลือกตำแหน่ง (หลัง/หัว/เอว) เลือก Rig แล้วกด แปลงเป็น Accessory ถ้าไม่เลือก Rig จะเก็บไว้ที่ ReplicatedStorage › SweetpropsAccessories เอาไปใช้ในเกมได้

เคล็ดลับให้งานออกมาสวย: บอก วัตถุ + วัสดุ + สี + รายละเอียดเด่น เช่น “wooden treasure chest, gold trims, glowing gems, slightly open lid” แล้วเลือกสไตล์ให้ตรงกับเกม ของชิ้นเดียวได้ผลดีกว่าฉากทั้งฉาก

3 · ปรับแต่งแบบมือโปร

  • จัดให้พร้อมใช้ — รวมเป็น Model ตั้ง Pivot ที่ฐาน ใส่ Anchored และการชนแบบ Hull
  • ลดภาระเกม — ปิดเงาชิ้นเล็ก ใช้การชนแบบกล่อง ตั้ง RenderFidelity อัตโนมัติ
  • วัสดุ AI — สร้าง MaterialVariant ใหม่จากคำอธิบาย ฟรีผ่าน Roblox
  • เอฟเฟกต์ — เรืองแสง ประกาย เส้นขอบ นีออน กลีบดอกลอย หัวใจลอย ออร่า หมุน ลอย เต้นตุบ ไฟ ควัน (เอฟเฟกต์ที่ขยับได้จะเห็นตอนกด Play)
  • ก๊อปและจัดเรียง — เรียงเป็นแถว เป็นวง เป็นตาราง หรือโปรยแบบสุ่มบนพื้น เหมาะทำป่า ทำรั้ว ทำโคมไฟถนน
  • ทุกคำสั่งกด Ctrl+Z ใน Studio ย้อนกลับได้

4 · คำสั่งด่วน

กด Ctrl+K ที่ไหนก็ได้ เพื่อค้นและสั่งงานกับโมเดลที่เลือกอยู่ทันที

แก้ปัญหา

  • ไม่เจอ Studio — เช็คว่าเปิด MCP server ใน Studio แล้ว และเปิด place อยู่ (ไม่ใช่หน้า Start Page)
  • ไม่พบ StudioMCP.exe — อัปเดต Roblox Studio หรือระบุ path ในหน้าตั้งค่า
  • สร้างช้า — ปกติใช้ 1–3 นาที ระหว่างนี้ยังใช้หน้าอื่นได้
  • อยากใช้ภาษาอังกฤษ — AI ของ Roblox เข้าใจภาษาอังกฤษดีที่สุด ภาษาไทยก็ใช้ได้

⚙ ตั้งค่า

StudioMCP

ตัวกลางที่ Sweetprops ใช้คุยกับ Roblox Studio (มากับ Studio) ปล่อยว่างไว้ให้หาเองอัตโนมัติ

Hugging Face token

สำหรับ “3D เหมือนรูป” — สมัครฟรีที่ huggingface.co แล้วสร้าง token แบบ Read ที่ Settings › Access Tokens โควต้าฟรีราว 3–5 ครั้ง/วัน

Roblox Open Cloud API key ไม่บังคับ

ถ้าใส่ โมเดล 3D จะอัปโหลดเข้าบัญชีและโผล่ใน Studio ให้เอง — สร้างที่ Creator Dashboard › Credentials ให้สิทธิ์ Assets: Read + Write ถ้าไม่ใส่ จะได้ไฟล์ .glb ไว้นำเข้าเองด้วย Import 3D
