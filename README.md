# Sweetprops 🍬

โปรแกรมสร้าง props ใน Roblox Studio ฟรี ไม่มีเครดิต ใช้ AI ของ Roblox ผ่าน **StudioMCP** ที่มากับ Studio อยู่แล้ว

## เริ่มใช้งาน

1. ติดตั้ง [Node.js](https://nodejs.org) 20 ขึ้นไป
2. ดับเบิลคลิก `Sweetprops.bat` (ครั้งแรกจะติดตั้งให้เอง) แล้วเบราว์เซอร์จะเปิด `http://127.0.0.1:34990`
3. เปิด Roblox Studio และเปิด place → **Assistant** → **⋯** → **Manage MCP Servers** → เปิด **Enable Studio as MCP server**
4. รอให้ไฟมุมซ้ายบนเป็นสีเขียว แล้วเริ่มสร้างได้เลย
5. (ไม่บังคับ) อยากได้ **3D เหมือนรูป** — ดับเบิลคลิก `Setup-3D.bat` ติดตั้งตัวสร้าง 3D ในเครื่อง (ดาวน์โหลด ~2.5GB ครั้งเดียว ต้องมี Python 3.10 และ git)

### ย้ายไปใช้คอมเครื่องอื่น

```bash
git clone https://github.com/blackpoi55/Sweetprops.git
```

แล้วดับเบิลคลิก `Sweetprops.bat` (และ `Setup-3D.bat` ถ้าจะใช้ 3D เหมือนรูป) คลังโมเดล (`data/library.json` + รูป) ติดมาด้วย ส่วนตั้งค่า/คีย์ต้องใส่ใหม่ในเครื่องนั้น

## ฟีเจอร์

| หน้า | ทำอะไรได้ |
|---|---|
| **สร้าง** | AI เมช (`generate_mesh`), ประกอบชิ้นส่วน (`generate_procedural_model`) · **จากรูป: การ์ด 2.5D เหมือนภาพ 100%** (ลบพื้นหลัง ผ่าซ้าย-ขวาพับ V อัปโหลดผ่าน `upload_image`) หรือ AI 3D ตามรูป · ครอปแผ่นแปลน · ดูดชุดสีจากรูป · สร้างพร้อมกัน 2–4 แบบ · โหมดคู่ (ตามรูป + AI เมช) · ชุดสำเร็จรูป · 12 สไตล์ · 4 ขนาด · 5 รูปทรง |
| **3D เหมือนรูป** | รูป → โมเดล 3D มีลาย ด้วย **TripoSR รันในเครื่อง (CPU) ฟรี 100% ออฟไลน์ ไม่ต้องสมัคร** (ติดตั้งครั้งเดียวด้วย `Setup-3D.bat`) ได้ไฟล์ .glb → Import 3D ใน Studio หรืออัปโหลดอัตโนมัติถ้าใส่ Open Cloud key · ถ้าไม่ได้ติดตั้งแต่ใส่ Hugging Face token จะใช้ TRELLIS บนคลาวด์แทน |
| **โหมดมือโปร** | ย้อมสีลาย (SurfaceAppearance.Color เก็บรายละเอียด) · ทองเงา + อัญมณีแก้วเรืองแสงตามชื่อชิ้น · แขวนจี้คริสตัล · โปรยดอกซากุระ/หัวใจ/ไข่มุกบนผิว · ปรับขนาดให้ตรง |
| **ปรับแต่ง** | วางหน้ากล้อง/วางลงพื้น/หมุน · ตั้งขนาดเป็น studs · ทาสี · วัสดุ 40+ แบบ · **วัสดุ AI** (`generate_material`) · เอฟเฟกต์ 12 แบบ (รวมกลีบดอกลอย หัวใจลอย ออร่า) · ฟิสิกส์ · ก๊อปเป็นแถว/วง/ตาราง · โปรยแบบสุ่ม · จัดให้พร้อมใช้ · ลดภาระเกม · ลบสคริปต์ · **แปลงเป็น Accessory แล้วใส่ให้ Rig** |
| **คลัง** | เก็บทุกโมเดลพร้อมรูป ใส่กลับใน place ไหนก็ได้ · ติดดาว · ส่งออก/นำเข้า |
| **ของฟรี** | ค้น Creator Store เฉพาะของฟรี วางหน้ากล้อง และลบสคริปต์ข้างในให้อัตโนมัติ |
| **คำสั่งด่วน** | `Ctrl+K` ค้นแล้วสั่งงานกับโมเดลที่เลือกได้ทันที |

ทุกคำสั่งที่แก้ของใน Studio กด `Ctrl+Z` ใน Studio ย้อนได้

## โครงสร้าง

```
server/
  index.js    HTTP server + API + คิวงานสร้าง (หลายแบบพร้อมกัน, การ์ด, มือโปร)
  mcp.js      ตัวเชื่อม StudioMCP.exe (หา path ให้อัตโนมัติ)
  studio.js   ขั้นตอนสร้าง/จัดวาง/ถ่ายรูป/คลัง/ของฟรี
  luau.js     สคริปต์ Luau ที่ส่งไปรันใน Studio
  prompts.js  แปลงตัวเลือกเป็น prompt และขนาด
  store.js    เก็บตั้งค่าและคลังเป็น JSON ใน data/ (token/key อยู่ใน data/settings.json บนเครื่องนี้เท่านั้น)
  cloud3d.js  รูป → 3D ผ่าน Gradio queue ของ Hugging Face Space
  opencloud.js อัปโหลด .glb เข้า Roblox ด้วย Open Cloud Assets API
  local3d.js  เรียกตัวสร้าง 3D ในเครื่อง (scripts/local3d/sweet3d.py)
scripts/local3d/  setup.ps1 (ติดตั้ง) + sweet3d.py (รูป → .glb ด้วย TripoSR บน CPU)
public/       หน้าเว็บ (HTML/CSS/JS ล้วน ไม่ต้อง build)
  imagekit.js ลบพื้นหลัง ครอป ผ่าครึ่ง ดูดสี วาดลายกลีบดอก/หัวใจ (ทำในเบราว์เซอร์)
scripts/probe.js   เช็คการเชื่อมต่อ StudioMCP
test/         unit tests (npm test)
```

## คำสั่งสำหรับนักพัฒนา

```bash
npm install
npm start          # เปิด server
npm run dev        # เปิดแบบรีสตาร์ทเองเมื่อแก้โค้ด
npm test           # รันเทสต์
node scripts/probe.js   # ดูว่าต่อ StudioMCP ได้ไหม และเจอ Studio กี่ตัว
```

ข้อมูลอยู่ในโฟลเดอร์ `data/` — คลังโมเดลถูกเก็บใน git ด้วย ส่วน `settings.json` (อาจมีคีย์), รูปอัปโหลด และไฟล์ .glb ไม่ถูก commit
